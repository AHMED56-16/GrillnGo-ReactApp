# 🔥 BBQ Recipe Menu App

A visually appealing and responsive **React app** that fetches BBQ recipes using the [Forkify API](https://forkify-api.herokuapp.com/). Built with modular components, live data integration, and clean design.

## 🚀 Features

- Real-time BBQ recipes from an API
- Fully responsive layout using Flexbox & Grid
- Reusable React components
- Error and loading state handling

## 🛠️ Stack

`React`, `JavaScript`, `CSS`, `REST API`
